# Resume — upload edition

ไฟล์ทั้งหมดอยู่ระดับเดียวกัน ไม่ต้องสร้างโฟลเดอร์ assets

1. แตก ZIP
2. GitHub: Add file → Upload files → choose your files
3. เลือกไฟล์ทั้งหมดในโฟลเดอร์ที่แตกไว้ แล้วอัปโหลด
4. Commit changes แล้วรอ GitHub Pages deploy

ต้องอัปโหลด index.html, styles.css และ script.js ชุดนี้พร้อมรูปและ PDF เนื่องจากอ้างอิงไฟล์ที่ระดับเดียวกัน

รูปจาก CV เก่าถูกนำมาใช้โดยไม่แก้ประวัติ ส่วน AI Local และโดรนเป็นภาพสร้างที่มีป้ายกำกับ
