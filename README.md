# Kanjanapong Singhatap — Engineering portfolio

เว็บไซต์ static สำหรับ GitHub Pages อิงทิศทางการจัดผลงานของเว็บ Kefan Wu โดยเขียนโค้ดและภาพประกอบใหม่ ไม่ใช้ภาพหรือผลงานของเจ้าของเรฟ

## เปิดดู
แตก ZIP แล้วเปิด index.html โดยเก็บไฟล์ทั้งหมดและโฟลเดอร์ assets ไว้ด้วยกัน รองรับการเปิดในเครื่องโดยไม่ต้องมีเซิร์ฟเวอร์

## ฟังก์ชัน
- ตารางผลงาน 3 คอลัมน์ ปรับเหลือ 2 และ 1 ตามความกว้างหน้าจอ
- กรอง All / Product / Analysis / Fabrication / Personal
- ค้นหาชื่อผลงาน บริษัท และเครื่องมือ
- กดการ์ดเพื่ออ่านบทบาท ขั้นตอน ผลลัพธ์ และสถานะงาน
- ปิดรายละเอียดด้วย Close หรือ Escape
- เปิด CV ตัวจริงจากเมนู Résumé

## ข้อมูลและภาพ
ประสบการณ์อาชีพใช้ข้อมูลจาก CV ที่ส่งมา ส่วน AI Local และโดรนใช้ประวัติโปรเจ็กต์ในแชต และแสดงสถานะว่ายังอยู่ระหว่างพัฒนาหรือเป็นแนวคิด

ภาพ SVG ทุกภาพเป็นภาพแผนผังประกอบที่สร้างใหม่ ไม่ใช่ภาพงานลูกค้า ไม่ใช่ผลจำลองจริง และไม่ใช่ CAD ที่ผ่านการตรวจสอบ ข้อความกำกับอยู่ทั้งบนการ์ดและหน้ารายละเอียด เมื่อมีภาพงานจริง ให้เปลี่ยนใน assets และแก้ข้อความกำกับตามข้อเท็จจริง

## นำขึ้น KS-Knp/Resume
1. แตก ZIP
2. อัปโหลด index.html, styles.css, script.js และโฟลเดอร์ assets ไปที่ root ของ repository แทนไฟล์เดิม
3. Commit แล้วรอ GitHub Pages deploy ด้วยการตั้งค่าเดิม
4. เปิด https://ks-knp.github.io/Resume/ และรีเฟรช

PDF ใน assets เป็นสำเนา CV ต้นฉบับครบทุกหน้า รวมข้อมูลส่วนตัวตามไฟล์ต้นฉบับ การอัปโหลด assets จะเผยแพร่ PDF นี้ด้วย

## แก้ไขภายหลัง
- เนื้อหาหน้าหลัก: index.html
- สี การจัดหน้า และมือถือ: styles.css
- ข้อมูลหน้ารายละเอียดและการทำงาน: script.js (ตัวแปร projects)
- projects.json เป็นสำเนาข้อมูลอ้างอิง ไม่ถูกโหลดโดยหน้าเว็บ

## การตรวจ
ตรวจโครงสร้าง HTML, ลิงก์ภายใน, ไฟล์ภาพ/PDF และไวยากรณ์ JavaScript แล้ว ทดสอบตรรกะกรอง ค้นหา และเปิด/ปิดรายละเอียดด้วย DOM จำลอง เครื่องมือเบราว์เซอร์ไม่สามารถเชื่อมต่อเซิร์ฟเวอร์แสดงตัวอย่างในเครื่องได้ จึงยังไม่ยืนยันการจัดวางภาพจริงหรือการพิมพ์
